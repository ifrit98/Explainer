An explanation compiler for Claude Code

Explainer

Ask a question. The agent builds a small model of the subject, then renders it in the simplest form that keeps the important structure: controlled prose, a diagram, an interactive page, or a narrated animation.

Compiler demo

One model, four renderings

Every rendering of softmax temperature is compiled from one model.md. The terms and the numbers are the same in each one. Normal routing would stop at Stage 3; this folder renders all four to show that they agree.

                  ┌─ 1 · controlled prose
question -> model ─┼─ 2 · diagram
                  ├─ 3 · interactive page
                  └─ 4 · animated video
Stage 1 · prose

Controlled prose

The procedure in numbered steps, the ratio law, a worked table, and the limits. Written in STE-80.

 Stage 2 · diagram

Diagrams

Where T acts in one decoding step, three distributions side by side, the causal chain, the limit states.

 Stage 3 · interactive

Interactive page

Move T and watch the bars, the pipeline table, and the ratio. Draw samples. Test shift invariance.

 Stage 4 · video

Narrated video

One tracker drives every object: dots move on the z/T line while the bars sharpen and flatten.
Stage 4 · Manim + local Kokoro voice · no API keys

Videos

Narration and animation stay in sync through bookmarks in the script. The local voice service synthesizes each bookmark segment separately, so every bookmark time is exact, with no Whisper pass.

Routing

The simplest medium that keeps the structure

StageUse when the subject is mainly…Escalate when…
1 · prosea procedure, a definition, an argument—
2 · diagramtopology, flow, architecturethe reader must hold three or more relationships at once
3 · interactivea parameter, scenarios, drill-downthe reader must explore states or alternatives
4 · videoa transformation over timeunderstanding depends on seeing state A become state B
Stage 1 · prose

Find the commit that introduced a bug

git bisect is a linear procedure with one loop. Numbered steps carry all of it, so the router stops here.

Stage 2 · diagram

What git stores when you commit

Blobs, trees, commits, and refs are pure topology. Nothing moves and nothing is tuned, so one diagram is enough.

Quick start

Run it

git clone https://github.com/ifrit98/Explainer.git && cd Explainer
brew install uv cairo pango pkgconf ffmpeg sox
uv sync && uv run explainer setup     # downloads the Kokoro voice (~350 MB)
claude                                # then: /explain <topic>  or  /video <topic>
