Agreeing on a secret over a public channel

Alice and Bob each pick a secret number and never send it. They send only public values computed from it. Eve can see everything in green. Change the numbers and see that Alice and Bob always end up with the same key. Then see how hard Eve has to work to get it. (The written explanation is in explanation.md.)

How Alice computes ga mod p quickly (repeated squaring)

Square repeatedly and reduce mod p every time. Then multiply together the squares that match the 1-bits of a. The number of steps grows with the number of digits of a, not with a itself.

Eve's attack: undo the exponent

Eve knows g, p and A. She needs some x with gx mod p = A. With no shortcut, she tries x = 1, 2, 3, … . (Any x that gives A works for her, because then Bx = Ab.)

Alice and Bob each share a key with Mallory, not with each other. Mallory can decrypt, read, re-encrypt and pass everything along without being noticed. The exchange alone can't stop this. Bob must prove that B came from him, for example with a digital signature backed by a certificate.
